# Slí — Irish transit + social iOS app

## Layout
- `ios/` — SwiftUI app, iOS 27, Liquid Glass. Project is generated by XcodeGen from `ios/project.yml` (the `.xcodeproj` is gitignored).
- `ios/Config/Secrets.xcconfig` — gitignored; copy from `Secrets.example.xcconfig` (SUPABASE_URL, SUPABASE_ANON_KEY).
- `supabase/migrations/` — Postgres schema + RLS.

## Commands
Xcode is not the active developer dir, so prefix with `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer`.

```sh
cd ios
xcodegen generate
xcodebuild -project Sli.xcodeproj -scheme Sli -destination 'platform=iOS Simulator,name=iPhone 18 Pro' -derivedDataPath build build
xcodebuild -project Sli.xcodeproj -scheme Sli -destination 'platform=iOS Simulator,name=iPhone 18 Pro' -derivedDataPath build test
xcrun simctl install booted build/Build/Products/Debug-iphonesimulator/Sli.app && xcrun simctl launch booted ie.sli.app -tab plans
```
Debug launch arg `-tab plans|friends|you` opens a specific tab (for screenshots).

## Conventions
- Swift 6 strict concurrency; `@MainActor @Observable` state in `AppState`.
- Services are protocols (`TransitService`) with mock implementations until backend is wired.
- Use `.glassEffect(...)`, `GlassEffectContainer`, `.buttonStyle(.glass/.glassProminent)` for chrome; `AuroraBackground` behind scroll content.
- Leap / TFI Go are hand-offs only (`TicketingHandoff`) — no payments in-app.
- Friend locations are read only via the `friend_locations` view (enforces approximate/paused/hide-list), never `live_locations` directly.
